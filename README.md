# Duongöndro for Android

Track your meditation practice together with your friends. End-to-end encrypted and fully open source.

Kotlin, Jetpack Compose and Material 3, down to Android 9 (API 28). Design: [duongondro-design](https://github.com/Duongondro/duongondro-design).

```sh
make core-test   # streak engine and practice logic on the JVM, against the shared cases
make build       # debug APK
make install     # onto the running emulator
```
